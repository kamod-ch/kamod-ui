Ported Preact/Kamod dashboard catalog blocks take structure and behavior from the
uipkge React catalog (https://uipkge.dev/react/blocks/), which is distributed
under the MIT License.

This directory does not copy React, Next.js, lucide-react, Radix, or next-themes
runtime code. Layout, copy, and interaction are reimplemented with Preact, Kamod UI
primitives, Kamod Icons, Kamod theme APIs, and small SSR-safe SVG charts.
